# ⚡ 暗号快传（anhao-transfer）

一款**免登录、不限速、不经过网盘**的纯前端浏览器点对点（WebRTC P2P）文件与文字传输工具。  
双方打开网页输入同一个暗号，即可建立一对一端到端加密直连，部署到 GitHub Pages 后即可 24 小时免费在线使用。

---

## ✨ 核心特性

- **零服务器存储**：文件通过 WebRTC 端到端加密（DTLS）直接在双方设备间传输，不经过也不留存在任何服务器。
- **原画无损、不挑格式**：支持图片、视频、文档、压缩包、安装包等任意单文件，完整保留原文件质量。
- **支持文字/网址互发**：手机与电脑互传链接、验证码或一段文字非常顺手。
- **明亮 / 暗黑双主题**：一键切换并自动记住主题偏好，适配电脑与手机浏览器。
- **全链路安全与防呆设计**：
  - 默认生成 6 位防混淆加密随机暗号（排除 `0/O/1/I/l`），也支持自定义字母/数字/中文暗号（至少 4 位，本地哈希映射）。
  - **严格 1 对 1 锁房**：已连接时自动拦截第 3 台设备挤入。
  - **双重手动确认**：发件方手动同意连接 + 收件方确认文件名与大小后手动点“接收”，绝不静默下载。
  - **64 KB 分片 + 缓冲区背压流控**：避免大文件传输撑爆浏览器内存，实时显示进度与网速。
  - **完整性校验**：接收完毕严格校验总字节数一致后才保存并释放内存。
  - **防误关 & 5 分钟空闲自动断开**：传输中拦截误刷新/关闭；连上后 5 分钟无操作自动安全断开。

## 🚀 快速使用

1. **发送方**：打开网页 → 点击「生成房间并等待对方连接」→ 把暗号告诉对方。
2. **接收方**：打开同一网页 → 切换到「我要接收」→ 输入暗号并点击「连接」。
3. **建立连接**：发送方点击「同意连接」后，双方进入一对一加密直连状态。
4. **开始传输**：发送方拖拽/选择文件点击「发送文件」，接收方确认文件名与大小后点击「同意接收」即可无损保存。

## 🛠️ 本地运行与部署到 GitHub Pages

本项目采用纯静态 `HTML + CSS + 原生 JavaScript`，**无需安装 Node.js 或任何构建工具**：

- **本地体验**：直接双击 `index.html` 用浏览器打开即可使用。
- **免费上线（GitHub Pages）**：
  1. 将本项目代码推送到你的 GitHub 仓库。
  2. 进入仓库的 **Settings → Pages**。
  3. 在 **Branch** 下选择 `main` 分支和 `/ (root)` 目录，点击 **Save**。
  4. 等待约 1～2 分钟，即可获得 24 小时在线的专属网址！

## 🔒 隐私与使用须知

- **需双方同时在线**：点对点直连不提供离线网盘暂存，传输期间请双方保持网页打开（手机端请勿锁屏或切后台）。
- **关于网络 IP**：受 WebRTC 点对点直连协议特性限制，通信双方的网络 IP 彼此可见，建议用于**熟人之间或自有设备间互传**。
- **关于大文件**：建议单文件 500 MB 以内体验最佳；受限于部分严格的公司/校园防火墙，极少数跨网环境可能需要切换到同一 Wi-Fi 或手机热点。
