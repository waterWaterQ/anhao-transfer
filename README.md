# ⚡ 暗号快传（anhao-transfer）

一款**零第三方依赖、免登录、不经网盘**的纯前端浏览器点对点（WebRTC P2P）文件与文字传输工具。  
采用自研极简国内 MQTT over WebSocket 信令与浏览器原生 `RTCPeerConnection` / `RTCDataChannel`，支持部署到 GitHub Pages 后 24 小时免费在线使用。

👉 **在线体验**：https://waterwaterq.github.io/anhao-transfer/

---

## ✨ 核心特性

- **零外部第三方库、纯国内直连优先**：
  - 仅包含 `index.html`、`style.css`、`signal.js`、`app.js` 四个文件，不依赖任何国外 CDN。
  - 信令直连中国大陆 EMQX 公共节点（`broker-cn.emqx.io`），内置腾讯、小米、芒果、B 站等国内公共 STUN 节点。
- **端到端加密、零服务器存储**：
  - 文件与文字通过 WebRTC DTLS 端到端加密通道传输，**不经过也不保存在任何服务器**。
  - 握手完成后自动基于双方真实 DTLS 证书指纹导出 **4 位安全核对码（如 `🛡️ K9-MT`）**，便于独立核验对端身份、防范中间人。
- **原画无损、高吞吐引擎**：
  - 支持任意格式单文件无损传输，顺便支持互发文字与网址。
  - 采用 `2 MB` 双缓冲流水线预读 + `16 KB` `Uint8Array` 零拷贝分片 + `1~2 MB` 事件驱动流控窗口 + 接收完毕总字节数严格校验。
  - 局域网实测可达 **15～24 MB/s**。
- **完善的安全与防呆设计**：
  - 默认生成 6 位防混淆随机暗号（排除 `0/O/1/I/l`），也支持自定义字母/数字/中文暗号（至少 4 位，本地双哈希映射，服务器不可见明文）。
  - 建房前自动查重、查无此房 4.5 秒快速提示、**严格 1 对 1 锁房拦截第 3 人**。
  - 发件方手动同意连接 + 收件方确认文件名与大小后手动接收（防 XSS 纯文本渲染，绝不静默下载）。
  - 支持 ICE 代次隔离、手机切网 4 秒宽限与有界 `restartIce()` 恢复、防误关提醒、5 分钟空闲自动断开。
- **自带 TURN 扩展与分阶段诊断面板**：
  - 内置折叠式 **「⚙️ 连接诊断与自带 TURN 设置」**，精确记录每阶段毫秒级耗时、候选类型统计（`host/srflx/relay`）与 W3C 标准 `selectedCandidatePairId` 选路结果。
  - 支持高级用户填入自有或免费 TURN 服务器（仅存本地浏览器）及切换 `all / relay` 选路策略，轻松穿透运营商对称型 NAT（如手机 5G）。

## 🚀 快速使用

1. **发送方**：打开网页 → 点击「生成房间并等待对方连接」→ 把暗号告诉对方。
2. **接收方**：打开同一网页 → 切换到「我要接收」→ 输入暗号并点击「连接」。
3. **建立连接**：发送方点击「✅ 同意连接」后，双方顶部会显示线路类型与 **4 位安全核对码**。
4. **开始传输**：发送方拖拽/选择文件点击「发送文件」，接收方确认文件名与大小后点击「✅ 同意接收」即可无损保存。

> 💡 **跨网 5G / 对称型防火墙提示**：若双方处于严格运营商对称型 NAT 且无公网 IPv6，可展开页面底部的 **「⚙️ 连接诊断与自带 TURN 设置」**，填入免费的 ExpressTURN / Metered.ca 或自建国内 `coturn` 地址并点「保存」，即可实现 100% 穿透。

## 🛠️ 本地运行与部署

纯静态项目，无需 Node.js 或构建工具：
- **本地运行**：直接用浏览器打开 `index.html` 或使用任意静态服务器托管。
- **GitHub Pages 部署**：Fork / 推送本仓库后，在 **Settings → Pages** 选择 `Deploy from a branch` → `main` → `/ (root)` 保存即可。

---

## 🔒 隐私与使用须知

- **需双方同时在线**：点对点传输不提供离线网盘暂存，传输期间请双方保持网页打开（手机端请勿锁屏或切后台）。
- **关于网络 IP**：直连模式下 WebRTC 协议特性会使通信双方彼此可见网络 IP，建议用于**熟人之间或自有设备间互传**。
- **关于大文件**：建议单文件 500 MB 以内体验最佳。
